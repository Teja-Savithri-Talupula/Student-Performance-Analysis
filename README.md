# Student-Performance-Analysis
📌 Project Overview
This project analyzes student performance using a small dataset of 15 records. The data includes subject scores and attendence percentages. Using Python(pandas,Matplotlib) and Excel, the project calculates averages and visualizes student performance trends.
📁 Dataset
Created manually in Excel with the following columns:
* Student_ID
* Name
* Stats
* Python
* Excel
* SQL
* Power BI
* Attendence(%)
SAVED AS : student_data.csv

🛠️ Tools & Libraries Used
* Python 3
* Pandas
* Matplotlib
* Excel(for initial data entry)

📊 Key Features
* load and clean CSV data
* Calculate average scores for each student
* Visualize average scores with bar charts
* Identity top-performing and underperforming students
